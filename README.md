# Gamestore - Интернет-магазин компьютерных игр

## О проекте

Gamestore — это веб-приложение для продажи компьютерных игр в цифровом формате. Приложение разработано с использованием современного стека технологий и предоставляет пользователям удобный интерфейс для покупки игр, управления профилем и отслеживания заказов.

### Основные возможности

**Для всех пользователей:**
- Просмотр каталога игр с поиском и фильтрацией по жанрам
- Регистрация и авторизация
- Добавление игр в корзину и оформление заказов
- Личный кабинет с историей покупок
- Переключение светлой/тёмной темы (сохраняется в localStorage)
- Адаптивный дизайн для всех устройств

**Для администратора:**
- Панель управления с разделами "Пользователи" и "Игры"
- CRUD операции для управления пользователями
- Добавление, редактирование и удаление игр

## Технологический стек

### Frontend
| Технология | Назначение |
|------------|------------|
| React 18 | Библиотека для построения пользовательского интерфейса |
| TypeScript | Типизация кода |
| Vite | Сборщик проекта |
| React Router DOM v6 | Маршрутизация |
| Context API | Управление глобальным состоянием |
| CSS Variables | Поддержка светлой и тёмной темы |
| PrimeIcons | Библиотека иконок |

### Тестирование
| Инструмент | Назначение |
|------------|------------|
| Cypress | E2E и компонентное тестирование |
